# 負荷テスト手順

## 1.アカウント配布

９月１０日の朝に、クラ代に星陵祭当日も使用する本番用のアカウントを生徒に配布します。
QRコードに書いてある番号が、自分の生徒番号と一致しているか確認してください。  
例）28R 1番　→ < STUDENT 2801 >

## 2.アカウントにログイン

[2026年度星陵祭公式サイト](https:2026.seiryofes.com)でアカウントにログインします。[詳しくはこちら](../guest/login.md)

## 3.グループ作成

アカウントにログインできたら、クラス内で1人以上6人以下のグループを作成します。[詳しくはこちら](../guest/team.md)


## ４.抽選申込

放送の指示に従い、全校生徒で一斉に31Rの抽選申し込みを行います。[詳しくはこちら](../guest/tickets.md)

## 5.抽選結果確認

[抽選結果ページ](https://2026.seiryofes.com/lotteryResult)から、抽選結果を確認します。

## ６.先着申込

放送の指示に従い、全校生徒で一斉に11Rの先着申し込みを行います。[詳しくはこちら](../guest/tickets.md)

## 負荷テストを行う際の補足と注意
- 負荷テスト当日は、各学年の各フロアにIT委員会技術部員を配置します。全クラスでの確認が取れてから次の手順に進むので、クラ代の方は円滑な状況報告にご協力をお願いいたします。また、エラーや不具合がありましたら技術部員までお願いいたします。
- 放送をよく聞いて、指示に従って行動をお願いいたします。
- 負荷テストで配布するQRコードは星陵祭当日も使用します。無くさないような管理をお願いいたします。
