# グループ機能

## 1.グループにメンバーを追加

左上の三本線をクリックしてください。
![説明用画像１](images/1.png)

「グループ機能」ボタンをクリックしてください。
![説明用画像1](team_images/1.png)

「QRコードをスキャン」を押してください。
![説明用画像1](team_images/2.png)

グループに追加したい人のアカウントのQRコードを読み取ってください。
グループに追加したい人が初回ログインの場合、以下のようにニックネームを求められます。
![説明用画像1](team_images/3.png)

初回ログインの場合はニックネームを入力し、「保存する」を押します。
![説明用画像1](team_images/4.png)

「現在のグループ状況」にアカウントが追加されれば成功です。
![説明用画像1](team_images/6.png)


## 2.グループから脱退

「グループから脱退する」ボタンを押します。
![説明用](team_images/5.png)

「脱退する」ボタンを押します。
![説明用](team_images/8.png)

「現在のグループ状況」に「グループがありません」と表示され、脱退が成功します。

脱退後は新しくグループを作ったり、他のグループに参加したりすることができます。
